## 5. Parser Recommendations

### Same Parser Can Handle Both ✅

**Recommendation:** Use ONE parser with minimal conditional logic:

```python
class ActivityStatementParser:
    def parse(self, pdf_path: str) -> ActivityStatement:
        # Step 1: Determine report type (MONTHLY vs DAILY)
        report_type = self._detect_report_type(pdf_path)
        
        # Step 2: Extract header & period
        header = self._parse_header(pdf_path)
        
        # Step 3: Extract overview (same for both)
        overview = self._parse_overview(pdf_path)
        
        # Step 4: Extract by account type (same structure)
        invest = self._parse_invest_account(pdf_path)
        cfd = self._parse_cfd_account(pdf_path)
        crypto = self._parse_crypto_account(pdf_path)
        
        # Step 5: Return unified object
        return ActivityStatement(
            report_type=report_type,
            period_start=header.start_date,
            period_end=header.end_date,
            overview=overview,
            invest_account=invest,
            cfd_account=cfd,
            crypto_account=crypto
        )
```

### Conditional Logic Needed

**1. Report Type Detection:**
```python
def _detect_report_type(self, pdf_path: str) -> str:
    # Read first page, check date range
    if start_date == end_date:
        return "DAILY"
    elif end_date.day == 30 or 31:  # Month end
        return "MONTHLY"
    else:
        return "INTERVAL"
```
