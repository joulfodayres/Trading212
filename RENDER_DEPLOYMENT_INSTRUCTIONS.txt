PASSO 1: Abre Render Dashboard
  URL: https://dashboard.render.com
  Login: Com a tua conta (Render ou GitHub)

════════════════════════════════════════════════════════════════════════════

PASSO 2: Criar novo Web Service
  Clica: "New +" (botão azul canto superior direito)
  Seleciona: "Web Service"

════════════════════════════════════════════════════════════════════════════

PASSO 3: Conectar GitHub
  Clica: "Connect Repository"
  Autoriza GitHub se pedir
  Seleciona: joulfodayres/Trading212

════════════════════════════════════════════════════════════════════════════

PASSO 4: Configurar Serviço

  Name: trading212-bot-api

  Runtime: Python 3

  Build Command:
    pip install -r backend/requirements.txt

  Start Command:
    cd backend && uvicorn main:app --host 0.0.0.0 --port $PORT

  Region: Frankfurt (ou mais perto de ti)

  Plan: Free (ou Starter se quiseres)
