Quick Start: Backend

# Clone repository git clone https://github.com/joulfodayres/Trading212.git cd Trading212 # Create Python virtual environment cd backend python -m venv venv # Activate virtual environment # On Windows: venv\Scripts\activate # On macOS/Linux: source venv/bin/activate # Install dependencies pip install -r requirements.txt # Create .env file (copy from .env.example) cp .env.example .env # Edit .env with your credentials # Run backend server uvicorn main:app --reload # Available at http://localhost:8000 # API docs at http://localhost:8000/docs

Quick Start: Frontend

# In a new terminal, from project root cd frontend # Install dependencies npm install # Create .env file cp .env.example .env # Edit .env with backend URL # Run development server npm run dev # Available at http://localhost:5173 # Build for production npm run build # Preview production build npm run preview

Common Solutions

🔄
Backend Won't Start
Problem: "Connection refused" or "Port already in use"

Solution:
  1. Check if port 8000 is in use: `netstat -an | grep 8000`
  2. Kill existing process or change port: `uvicorn main:app --port 8001`
  3. Verify .env file exists and is correct
  4. Check requirements.txt: `pip install -r requirements.txt`
🔐
Login Failed
Problem: "Invalid credentials" or infinite loop

Solution:
  1. Check SUPABASE_URL and SUPABASE_KEY in .env
  2. Verify email exists in Supabase Auth
  3. Check browser console for 401 errors
  4. Clear localStorage and try again
⚙️
Automation Not Running
Problem: Scheduler shows running but orders not placed

Solution:
  1. Check backend logs for scheduler errors
  2. Verify T212_API_KEY and T212_API_SECRET in .env
  3. Check automation enabled: GET /api/v1/automation/status
  4. Review strategy parameters for pos -1, 0, 1

For more issues and detailed solutions, see TROUBLESHOOTING.md.
