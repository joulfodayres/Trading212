⚙️ Infrastructure & Tools

🏛️

Production Stack

Frontend: React 18 + TypeScript (Render)
Backend: FastAPI + Python 3.14 (Render)
Database: PostgreSQL (Supabase)
Auth: Supabase Auth (JWT)

All services hosted on Render + Supabase. Auto-deploy from GitHub.

🔐

Security & Credentials

API Keys: Encrypted with Fernet
JWT Tokens: Via Supabase Auth
Database: Row-Level Security (RLS) on all tables
Transport: HTTPS everywhere

All sensitive data in .env (gitignored). Never committed.

📈

Performance Metrics

Frontend Build: 5-10 min
Backend Start: 2-3 min
T212 API: ~500ms response
DB Query: <100ms

Automation cycle: 7-10s execution + 5-8s buffer.
