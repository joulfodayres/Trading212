🔧 PASSO-A-PASSO (5 fases):

FASE 1: GITHUB
  1. git init
  2. git add .
  3. git commit -m "Initial commit"
  4. git push para GitHub

FASE 2: SUPABASE
  1. Criar projeto em supabase.com
  2. Executar SQL scripts (db/supabase_schema.sql)
  3. Copiar credenciais (SUPABASE_URL, SUPABASE_KEY, JWT_SECRET)

FASE 3: RENDER BACKEND
  1. Criar Web Service em Render
  2. Conectar GitHub
  3. Configurar env vars (SUPABASE_*, T212_*, JWT_*)
  4. Deploy automático

FASE 4: RENDER FRONTEND
  1. Criar segundo Web Service em Render
  2. Mesmo repositório GitHub
  3. Build command: cd frontend && npm install && npm run build
  4. Start command: npm run serve
  5. Deploy automático

FASE 5: TESTAR
  1. Abrir frontend no browser
  2. Verificar login page
  3. Verificar dashboard
  4. Testar endpoints no Swagger (/docs)
